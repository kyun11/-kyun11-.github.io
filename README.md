## 사이트 주소

GitHub Pages 활성화 후:

https://kyun11.github.io/-kyun11-.github.io/

## Pages 켜는 방법 (1회)

1. https://github.com/kyun11/-kyun11-.github.io/settings/pages
2. **Source** → **GitHub Actions** 선택 (또는 Deploy from a branch → `main` / `/`)
3. Actions 탭에서 실패한 `Deploy GitHub Pages` 워크플로 **Re-run**

루트 주소 `https://kyun11.github.io` 를 쓰려면 저장소 이름을 `kyun11.github.io` 로 바꿔야 합니다.
